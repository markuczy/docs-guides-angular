[#translations]
= Translations

In OneCX, multi-language support is available via translations. This page is a deep dive into setting up and using `@ngx-translate`-based translations in Angular applications, and the translation-resource wiring used by React applications. See xref:documentation:docs-guides-ui:setup/recommended/configure-translations.adoc[Configure Translations] for the introductory checklist item.

[#angular-applications]
== Angular Applications

* xref:documentation:docs-guides-ui:concepts/translations/angular-setup.adoc[Setup] — installing and configuring `@ngx-translate` for multi-language support.
* xref:documentation:docs-guides-ui:concepts/translations/angular-usage.adoc[Usage] — using translations in templates and components, and accessing the current language.

[#react-applications]
== React Applications

* xref:documentation:docs-guides-ui:concepts/translations/react-setup.adoc[Setup] — wiring translation resources into the `i18next` backend via `@onecx/react-utils`.
* xref:documentation:docs-guides-ui:concepts/translations/react-usage.adoc[Usage] — keeping the current language in sync via `TranslationBridge`.
