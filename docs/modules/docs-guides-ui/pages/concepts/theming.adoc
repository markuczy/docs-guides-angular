[#theming]
= Theming

In OneCX, each workspace can use a different theme for its pages. Each theme defines the same set of CSS variables, available on every page, but with different values. The availability of those CSS variables is handled by the OneCX shell based on the accessed workspace — an app does not have to do anything to apply the theme itself. The only responsibility is to use theme variables in its own styles instead of hard-coded values.

This page is a deep dive into the available theme variables and how to use them. See xref:documentation:docs-guides-ui:setup/recommended/apply-theming.adoc[Apply Theming] for the introductory checklist item.

[#theme-appliance]
== Theme Appliance

As described above, applying a theme is handled entirely by the OneCX shell. Applications only need to consume the CSS variables it exposes.

[#theme-variables]
== Theme Variables

Theme variables are CSS variables available on the page for any application.

Below is a list of the theme variables available on the page:

[#basic-variables]
Basic Variables::
====
[cols="1,3"]
|===
|CSS variable
|Description
|`--primary-color`
|Primary color of non-text content.
|`--secondary-color`
|Secondary color of non-text content.
|`--content-bg-color`
|Default background color of non-text content.
|`--hover-bg-color`
|Default background color on hover of non-text content.
|===
====

[#utilizing-theme-variables]
== Utilizing Theme Variables

Regardless of whether your application is built with Angular or React, using a theme variable just means referencing the corresponding CSS variable in your styles — injecting and applying the variables' values is handled automatically. When creating styles for UI components, it's important to consider whether a style should be theme-aware. Example of a stylesheet using a theme variable:

.styles.css
[.source,css]
----
button {
    background-color: var(--primary-color);
}
----

The example above sets the background color for each button element to the value corresponding to the `--primary-color` theme variable.

NOTE: React applications that use PrimeReact additionally need to import a base theme stylesheet so PrimeReact styles align with OneCX theming. See xref:documentation:docs-guides-ui:react/libraries/react-utils.adoc[@onecx/react-utils] for the full library reference, including the PrimeReact theme base import and the underlying theme variable injection mechanism.
